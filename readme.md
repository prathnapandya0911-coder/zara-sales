| Command                    | Meaning                                                           |
| -------------------------- | ----------------------------------------------------------------- |
| `git init`                 | Creates a new Git repository in the current folder.               |
| `git status`               | Shows the current status of files (tracked, untracked, modified). |
| `git add file.txt`         | Adds a specific file to the staging area.                         |
| `git add .`                | Adds all files to the staging area.                               |
| `git commit -m "message"`  | Saves the staged changes with a message.                          |
| `git log`                  | Displays the commit history.                                      |
| `git clone <url>`          | Copies a remote repository to your computer.                      |
| `git push origin main`     | Uploads local commits to GitHub.                                  |
| `git pull origin main`     | Downloads the latest changes from GitHub.                         |
| `git branch`               | Lists all branches.                                               |
| `git branch branch_name`   | Creates a new branch.                                             |
| `git checkout branch_name` | Switches to another branch.                                       |
| `git merge branch_name`    | Merges a branch into the current branch.                          |
| `git remote -v`            | Shows connected remote repositories.                              |
| `git rm file.txt`          | Removes a file from Git and the local system.                     |
